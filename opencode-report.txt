D. LOGIC BILL GENERATION
--------------------------------------------------------------------------------
  Untuk setiap payment setting aktif siswa:
  - Resolve rate: payment_type_id + class_level siswa + tanggal target.
  - effective_from <= target; effective_until NULL (masih aktif) atau >= target.
  - Jika >1 rate cocok: pilih effective_from terbaru (orderByDesc).
  - is_monthly = true  => bill berperiode (period_month/year = target).
  - is_monthly = false => bill tanpa periode (Uang Pangkal).
  - SPP/Ekskul aktif & wajib via auto-enroll; opsional sesuai setting.
  - amount bill = amount rate (ORIGINAL, tidak pernah diubah pembayaran).
  - Bill dipakai sumber periode PaymentDetail (bukan now()).

E. DUPLICATE PREVENTION (application-level, idempotent)

  - Monthly : kunci (student_id, payment_type_id, period_month, period_year)
              sudah ada => skip.
  - Non-monthly : ada bill student+type dgn period NULL & belum lunas => skip.
  - Generate 2x periode sama => tetap 1 bill (diverifikasi test).
